# GardenOS v0.1

A local-first GardenOS prototype.

## Run it

Open `index.html` directly in Chrome, Safari, Firefox, or Edge.

No server, install, account, or build step is required.

## Included

- Today dashboard
- Garden sections
- Grouped plantings
- Task management
- Observation journal
- Local browser persistence
- Responsive desktop and mobile layouts
- Basic rule-based recommendations

## Data

The prototype stores all data in browser localStorage under:

`gardenos-v01`

Use Settings → Reset demo data to restore the sample dataset.
