# PRD 001 — Voice Capture with GPS

## Goal
Ship the smallest useful GardenOS experience for a single user:

1. Open the app on a phone.
2. Tap one large button.
3. Record a voice note.
4. Capture latitude, longitude, GPS accuracy, and timestamp.
5. Save everything locally on the device.
6. Show a chronological list.
7. Tap an item to play the original recording.

## Non-goals
- No transcription.
- No AI processing.
- No accounts.
- No cloud sync.
- No map.
- No multi-user support.
- No plant database.

## Primary flow
1. User opens the app.
2. Browser requests microphone and location permissions.
3. User taps Record.
4. App records audio while requesting the current GPS position.
5. User taps Stop.
6. App stores the audio blob and metadata in IndexedDB.
7. New recording appears at the top of the list.
8. User taps Play to listen.

## Data model

### Recording
- id: string
- createdAt: ISO timestamp
- durationMs: number
- audioBlob: Blob
- mimeType: string
- latitude: number | null
- longitude: number | null
- accuracyMeters: number | null
- locationStatus: "captured" | "denied" | "unavailable"
- note: string | null

## Acceptance criteria
- Works on a modern mobile browser.
- Record button is the dominant action.
- Audio survives page refresh.
- GPS coordinates are stored with each recording when permission is granted.
- User can replay and delete recordings.
- App works offline after first load.
- No form is required before recording.
- Status is always visible: ready, recording, saving, or error.

## Technical approach
- Static PWA.
- MediaRecorder API for audio.
- Geolocation API for coordinates.
- IndexedDB for durable local storage.
- Service worker for offline shell caching.
- No framework and no build step.
