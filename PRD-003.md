# PRD 003 — Production GPS Only

## Goal
Ensure the deployed app stores and displays only real device geolocation.

## Changes
- Removed the preview/demo button.
- Removed every hardcoded latitude and longitude.
- New recordings are marked with `source: "gps"`.
- Legacy records marked as demo data are removed on startup.
- Demo records are excluded from the recording list.
- Geolocation uses:
  - `enableHighAccuracy: true`
  - `maximumAge: 0`
  - `timeout: 20000`

## Acceptance criteria
- No simulated coordinate exists in the production source.
- New recordings use only the browser Geolocation API.
- Legacy demo entries disappear automatically.
- Real recordings retain audio, timestamp, accuracy, and coordinates.
